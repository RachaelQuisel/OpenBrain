# Combine a set of sources into clear findings, disagreements, missing evidence, and questions for the decision at hand

This skill helps you combine a set of sources into clear findings, disagreements, missing evidence, and questions for the decision at hand.

## What to share

State the question or decision, share the sources you want considered, and identify the intended reader.

## How to start

Select this skill and describe your request. The assistant uses the information and tools available in that conversation.
